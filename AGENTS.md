# Agent instructions: standards-marketplace

This repository is the index and shared tooling for the Slight76 standards handbooks. It holds governance rules (GOV-*), templates, the consumer kit, and the Python tooling every handbook's CI uses.

## Working here

- Read [README.md](README.md) for the handbook routing table and install commands.
- Shared behaviour lives in `tooling/`. Change it with tests (`py -m unittest discover -s tooling/tests`) and run `py tooling/validate.py --root .` before finishing.
- `catalog/rule-index.json` is generated by `tooling/migration/split_repo.py`; after a handbook adds or retires rules, regenerate or hand-edit it and keep IDs unique across all handbooks.
- Templates and `scaffold/` are copied into other repositories; keep them generic and free of repo-specific wording.
- The validator rejects the retired corporate-layer wording (see architecture-standards ADR-0028) outside `adr/`, `CHANGELOG.md`, and `catalog/`; describe things as team standards.
- Preserve rule IDs. Retire with `status: Superseded` and `superseded_by`; never rename or reuse.
- Pin SHAs, not branches, in `.claude-plugin/marketplace.json` and consumer baselines.

## Skill

`skills/standards-marketplace/SKILL.md` routes agents to the right handbook for a task.
